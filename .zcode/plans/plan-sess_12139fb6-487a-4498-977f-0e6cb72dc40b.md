# 寰宇 Earth Geography — Three.js 交互地球仪

## 背景

`earth-geography` 是全新空仓库（仅 `git init`），从零搭建一个地理学习工具：暗色科技风的 3D 地球，hover 国家高亮显示信息，点击飞行 + 详情卡，带搜索。已确认决策：原生 Three.js + Vite + TypeScript、暗色科技风、仅桌面端、带搜索框、详情卡扩展版。

## 产品设计

**布局**（全屏 canvas + 悬浮 UI）
- 左上角：标题「寰宇」+ 副标题
- 顶部居中：搜索框（中/英文国名模糊匹配，下拉候选 ≤8 条，↑↓ 选择 + Enter，选中后飞行定位）
- hover：玻璃拟态 tooltip 跟随鼠标（国名中文+英文、大洲）
- 点击国家：相机飞至该国正面 → 右侧滑入详情卡
- 详情卡（扩展版）：flagcdn 旗帜图、中英文名、大洲/次区域、首都、人口、面积、官方语言、货币、时区、电话区号、邻国 chips（点击跳转飞行）
- 底部：操作提示（拖拽旋转 · 滚轮缩放 · 点击国家）
- 数据加载期间显示 loading 画面

**交互规格**
- OrbitControls：阻尼 + 缓慢自转（交互中暂停，空闲 3s 恢复）；缩放距离限制 ~1.6–4.5（地球半径=1）；禁用平移
- 点击海洋/ESC/关闭按钮 → 收起详情卡
- 飞行动画 ~1.2s，easeInOutCubic，球面插值到国家质心（`d3.geoCentroid`）

**视觉规范（暗色科技风）**
- 深空背景 #050510 + 两层程序化星点
- 海洋 #0a1a2f、大陆 #1a3a2f、静态国界青色细线（低透明度）
- 大气：BackSide 球 r≈1.15，fresnel shader 蓝紫辉光
- hover 填充亮青 #45d3e8（半透明），选中填充橙 #ff9d47，均叠加在独立高亮层

## 技术方案

**核心：颜色索引拾取**（不做多边形网格 raycast）
1. 用 `d3-geo` 的 `geoPath(geoEquirectangular)` 把每个国家画到 2048×1024 离屏 canvas，填充色编码国家索引（RGB 多通道编码）
2. `getImageData` 缓存；pointermove 时 raycast 主球 → `uv` → 换算像素 → 读索引 → 得到国家（O(1)，任意缩放精确，小国也能命中）
3. Three 球体 UV 与 equirect 经度偏移需校准，用已知国家（如中国、俄罗斯）验证

**渲染分层**（全部 canvas 纹理，总 draw call <6）
- 主球（静态纹理：海洋+大陆+国界线，零重绘）
- 高亮球（r=1.001，透明 canvas 纹理，hover/选中变化时才重绘一次；hover 国家边界同步加亮）
- 大气球、星空 Points

**飞行动画**：目标相机位置 = 质心方向 × 当前距离，四元数 slerp + easing，飞行期间暂停自转

**数据（全部离线打包，运行时零 API 依赖）**
- 几何：npm `world-atlas` 的 countries-110m.json（TopoJSON ~108KB）→ `topojson-client` 转 GeoJSON，feature.id 为 ISO 3166-1 numeric
- 属性：构建 `src/data/countries.json`，实现期一次性从公开数据集（首选 mledoze/countries：含中文翻译、首都、区域、border 邻国、货币、时区、区号；人口缺失字段用 restcountries 静态数据补齐）生成并提交仓库
- 邻国跳转：mledoze 的 borders 是 alpha3，与 numeric id 建映射表
- 旗帜：详情卡用 flagcdn.com 图片（唯一网络依赖，onerror 回退 emoji）；tooltip 用 emoji

```

  package.json  index.html  README.md

    main.ts            入口
    types.ts  state.ts（hover/选中状态 + 事件分发）
```

## 实现步骤

1. 脚手架：`npm create vite`（vanilla-ts）+ 依赖安装 + index.html + 全局样式
2. 数据：生成 countries.json，写类型与加载逻辑
3. 地球视觉：主纹理绘制、大气辉光、星空、OrbitControls 自转（先出可看的画面）
4. 拾取 + hover 高亮 + tooltip（含 UV 校准验证）
5. 点击飞行 + 详情卡 + 邻国跳转
6. 搜索框
7. 打磨：loading 画面、颜色细节、README（含数据来源说明）
